## Scope and limitations

This is an explicit Draft 2020-12 subset, not full conformance. Supported assertions include types, exact decimal bounds/multipleOf/equality, string and collection counts, uniqueness, tuple items, contains/minContains/maxContains matching counts, property schemas/patterns, const/enum, if/then/else conditional branches, dependentRequired/dependentSchemas object dependencies, applicators, and local JSON Pointer references with $defs. The manifest independently declares every vendored group. All groups are matched by file, index and exact description.

format is annotation only. External references, named anchors, $id, dynamic references, vocabularies, dependencies, propertyNames, unevaluatedItems, unevaluatedProperties and other undeclared assertions remain unsupported. Regex supports literals, dot, classes, ordinary groups, alternation, repetitions and anchors; unsupported mechanisms are rejected. Dot excludes four line terminators; whitespace uses the ECMAScript set. Count parameters are limited to 1000000000. Schema snapshots permit depth 128 and 100000 JSON nodes; evaluation permits 128 active schema calls and 100000 visits per record. Same-instance reference cycles and exhaustion are execution errors.

Every exclusion below identifies its group; per-test_index results and diagnostics are in the JSON report. Expected rejections count only as scope-policy compliance.
